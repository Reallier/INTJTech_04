# 文档分层与发布规范

## 三层可见度

- `public`：默认允许匿名访问，可被公开传播和搜索收录
- `restricted`：仅登录用户可见，适合客户交付、对接说明、准备清单
- `internal`：仅内部成员与管理员可见，适合架构、运维、故障、实验记录

## 发布原则

1. 默认从更严格层级开始，确认安全后再下调可见度。
2. 受限共享文档不放账号、密码、密钥、内网地址。
3. 内部文档禁止通过复制粘贴直接同步到公开页面。
4. 任何截图、代码块、日志在对外前都要做脱敏审查。

## 严禁外放的内容

- Token、API Key、SSH Key、数据库连接串
- 生产环境地址、端口、拓扑与故障日志
- 第三方平台后台入口与运维操作细节
