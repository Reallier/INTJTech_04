# App06 - Boss直聘求职Agent

## 核心价值

自动化求职助手，解放双手找工作。自动搜索职位并发送打招呼消息。

## 核心功能

### 智能搜索
- 多关键词、多城市
- 薪资范围筛选
- 公司规模筛选

### 黑名单过滤
- 屏蔽指定公司
- 屏蔽关键词（外包、外派等）

### 自动打招呼
- 可配置消息模板
- 随机延迟（30-60秒）
- 每日上限（默认50次）

## 安全机制

⚠️ **使用风险**：自动化操作可能违反平台规则

已实现的反检测策略：
- 随机延迟间隔
- 每日操作上限
- Cookie持久化（避免频繁登录）

## 配置项

| 配置 | 说明 | 默认值 |
|------|------|--------|
| `SEARCH_KEYWORDS` | 搜索关键词 | Python,后端 |
| `SALARY_MIN/MAX` | 薪资范围(K) | 15-30 |
| `BLACKLIST_COMPANIES` | 黑名单公司 | - |
| `GREET_INTERVAL` | 操作间隔(秒) | 30-60 |
| `DAILY_LIMIT` | 每日上限 | 50 |

## 技术栈

- 后端：FastAPI
- 浏览器自动化：DrissionPage
- 数据持久化：SQLite
