# App01 - TalentAI 智能招聘匹配系统

> 端口：`8001` | 状态：生产运行 | 版本：v4.0

## 核心价值

解决招聘场景中的**简历-JD匹配效率问题**。通过LLM深度语义分析，自动判断候选人与职位的匹配度，替代HR逐份阅读简历的传统方式。

## 功能概览

| 功能 | 说明 |
|------|------|
| **即时匹配** | 上传简历+JD，实时获取匹配评分 |
| **人才库管理** | 简历入库、去重、结构化存储 |
| **智能搜索** | 全文+语义向量混合搜索 |
| **安全防护** | Deep Defense v2.2 防注入系统 |

## 技术栈

- **后端**：FastAPI + SQLAlchemy + PostgreSQL
- **前端**：Nuxt 3 + Vue 3
- **AI服务**：Qwen-Max + Qwen-VL-OCR (DashScope)
- **部署**：Docker + Nginx
