# App02 - 简序智能客服

## 核心价值

官网访客的**第一接触点**。基于LLM意图识别，自动判断用户意图并给出相应回复，减少人工客服负担。

## 意图路由系统

采用**LLM-Only Router**架构，支持18种业务意图：

### 售前转化（P系列）
| 意图 | 触发条件 |
|------|----------|
| 方案匹配 | 用户表达需求/痛点 |
| 价值防御 | 提到价格/竞品/低代码 |
| POC申请 | 请求试用/Demo |
| 报价生成 | 索取正式报价 |

### 技术支持（S系列）
| 意图 | 触发条件 |
|------|----------|
| 状态查询 | 查订单/API额度 |
| 故障排查 | 报错/日志问题 |
| 文档检索 | 功能/参数/使用方法 |

### 通用意图
- **闲聊**：你好、在吗、测试
- **公司介绍**：你们是谁
- **产品介绍**：有哪些产品
- **转人工**：明确要求人工

## 路由策略

核心原则：**宁缺毋滥**

1. 无明确业务需求 → 不归类为业务意图
2. 纯问候 → CHITCHAT
3. 无意义输入 → IRRELEVANT
4. 只有包含"需求"、"痛点"、"产品"等才细分业务意图

采用思维链（CoT）推理，在`reasoning`字段记录判断过程。

## 技术栈

- 前端：Streamlit
- LLM：qwen-turbo（快速响应）
- 部署：Docker

## 配置

| 环境变量 | 说明 |
|----------|------|
| `CLOSER_OPENAI_API_KEY` | DashScope API Key |
| `CLOSER_ROUTER_MODEL` | 路由模型，默认qwen-turbo |
