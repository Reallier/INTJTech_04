# App03 - MindAI Typing MBTI判型

## 核心价值

通过**自然对话**帮助用户发现MBTI类型。与传统测试的区别：

| 传统MBTI测试 | MindAI Typing |
|-------------|---------------|
| 直接问"你是什么人" | 观察"你怎么处理问题" |
| 假设用户有自知之明 | **假题策略**避免自述偏差 |
| 选择题形式 | 开放式对话 |

## 核心算法：假题策略

**不问用户偏好，而是通过回答方式判断认知功能**

### 假题类型设计

| 题型 | 表面目的 | 真实洞察 |
|------|----------|----------|
| 场景决策题 | 了解偏好 | 判断功能(Te/Ti/Fe/Fi) |
| 问题解决题 | 了解思维 | 感知功能(Se/Si/Ne/Ni) |
| 价值冲突题 | 了解立场 | Fi/Fe取向 |
| 开放联想题 | 了解想法 | Ne/Ni模式 |

**示例：**
- "朋友创业邀请你，你考虑哪些因素？" → 判断Te/Ti/Fe/Fi
- "遇到从没见过的故障怎么排查？" → 判断Se/Si/Ne/Ni

## 荣格八维认知功能

| 功能 | LLM识别信号 |
|------|-------------|
| **Ti** | 追问定义精确性、质疑逻辑漏洞 |
| **Te** | 快速切入"怎么做"、引用数据 |
| **Fi** | 强调"我觉得"、有个人底线 |
| **Fe** | 考虑他人感受、用"我们" |
| **Ni** | 直接给结论、跳跃式思维 |
| **Ne** | "或者"/"也可能"、发散联想 |
| **Si** | 参考过去经验、注意细节 |
| **Se** | 关注当下环境、感官描述 |

## 16型功能堆栈

```
INTJ: Ni-Te-Fi-Se    INFJ: Ni-Fe-Ti-Se
INTP: Ti-Ne-Si-Fe    INFP: Fi-Ne-Si-Te
ENTJ: Te-Ni-Se-Fi    ENFJ: Fe-Ni-Se-Ti
ENTP: Ne-Ti-Fe-Si    ENFP: Ne-Fi-Te-Si
...
```

## 部署与鉴权（重要）

### 鉴权策略

- 服务使用 JWT（Cookie `auth_token`）进行认证，**所有 `/api/*` 默认强制登录**
- 开发调试可设置 `DEV_MODE=true` 跳过认证
- 兼容 SSO Redirect：支持入口 `/?token=...` 换取 Cookie，随后会重定向到干净 URL（避免 token 泄露到 Referer/浏览器历史等）

### Traefik / 网关说明

- 线上 Traefik 路由标签未配置 `middlewares`（即网关层不强制 SSO）
- 请不要“仅依赖网关鉴权”，应用侧已做强制校验；如未来加网关鉴权，也建议保留应用侧校验作为兜底

### 日志与隐私

- 应用侧访问日志不记录 query/header/body，避免泄露 token 与对话内容
- 对话与测试数据长期留存在 SQLite（`sessions/messages/typing_results`），当前不做自动清理
