# App07 - 简历优化Agent

## 核心价值

通过LLM多段提示词**精修简历**，提升求职竞争力。

## 优化策略

| 策略 | 方向 | 示例 |
|------|------|------|
| **信息密度** | 量化成果 | "提升效率" → "提升效率30%" |
| **表达术语** | 专业化 | "负责" → "主导/设计/推动" |
| **信息广度** | 扩展描述 | 补充技术栈、业务价值 |

## 使用流程

1. 上传简历（DOCX/PDF/TXT）
2. 自动分段解析
3. 按策略逐段优化
4. 导出Markdown

## 技术栈

- 后端：FastAPI
- LLM：OpenAI API / DashScope
- 文档解析：python-docx, PyPDF2
