# 整体架构

## 系统全景

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户访问层                                 │
│  官网 (intjtech.reallier.top) │ 各应用前端 │ API 调用            │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│                      Traefik 反向代理                            │
│                  (TLS 终止、路由、负载均衡)                       │
└─────────────────────────────────────────────────────────────────┘
                                │
        ┌───────────────────────┼───────────────────────┐
        ▼                       ▼                       ▼
┌──────────────┐    ┌──────────────────┐    ┌──────────────────┐
│   应用服务    │    │    AI 服务       │    │   基础服务        │
├──────────────┤    ├──────────────────┤    ├──────────────────┤
│ App01-11     │    │ DashScope API    │    │ PostgreSQL       │
│ 官网         │    │ OpenAI API       │    │ SQLite           │
│              │    │ Ollama (本地)    │    │                  │
└──────────────┘    └──────────────────┘    └──────────────────┘
        │                                           │
        └───────────────────┬───────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                      可观测性栈                                   │
│  Prometheus (指标) │ Loki (日志) │ Grafana (可视化)              │
└─────────────────────────────────────────────────────────────────┘
```

## 技术栈概览

| 层级 | 技术选型 |
|------|----------|
| **前端** | Vue 3 / Nuxt 3 / 原生 HTML |
| **后端** | FastAPI / Streamlit |
| **数据库** | PostgreSQL / SQLite |
| **LLM** | DashScope (qwen) / OpenAI / Ollama |
| **部署** | Docker + Traefik |
| **监控** | Prometheus + Loki + Grafana |
