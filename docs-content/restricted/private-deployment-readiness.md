# 私有化部署准备清单

本文档用于交付前对齐准备事项，只描述边界与前置条件，不包含账号、密码、密钥或任何内网地址。

## 需要提前确认的内容

- 部署形态：单机、专有云或客户自有 Kubernetes
- 资源规模：CPU、内存、磁盘、对象存储预算
- 合规要求：数据留存、访问审计、网络隔离
- 接入范围：SSO、邮件、短信、监控、日志导出

## 建议由客户侧准备

- 一个明确的对接人和审批路径
- 可用于部署的基础环境说明
- 测试数据或脱敏样例数据
- 验收标准与上线窗口

## 不会通过本文档提供的内容

- 生产环境凭证
- 管理员初始密码
- 服务器 SSH 信息
- 数据库连接串
