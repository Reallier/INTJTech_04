# 文档处理类

处理各类文档格式的 Agent 技能包。

---

## docx

> Word 文档读写与格式化

**场景**：
- 读取 .docx 文件内容
- 生成格式化 Word 文档
- 批量文档处理

**安装**：
```bash
git clone https://github.com/ComposioHQ/awesome-claude-skills.git ~/.gemini/skills/composio
```

**来源**：[awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills) ⭐ 20.7k

**触发示例**：
- "读取这个 Word 文档"
- "生成一份报告文档"
