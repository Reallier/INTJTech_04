## csv-processor

> CSV 数据清洗与转换

**场景**：
- 批量数据清洗
- 格式转换（CSV ↔ JSON）
- 数据验证与修复

**安装**：
```bash
git clone https://github.com/Prat011/awesome-llm-skills.git ~/.gemini/skills/llm-skills
```

**来源**：[awesome-llm-skills](https://github.com/Prat011/awesome-llm-skills) ⭐ 690

**触发示例**：
- "清洗这个 CSV 文件"
