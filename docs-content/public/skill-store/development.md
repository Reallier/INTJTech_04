# 开发代码类

专注于软件开发工作流的 Agent 技能包。

---

## code-review

> 自动化 PR 审查与代码逻辑分析

**场景**：
- 代码审查流程自动化
- PR 合并前的质量把关
- 发现潜在 Bug 和架构问题

**安装**：
```bash
# 用户级
git clone https://github.com/hesreallyhim/awesome-claude-code.git ~/.gemini/skills/claude-code
```

**来源**：[awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code) ⭐ 20.7k

**触发示例**：
- "帮我审查这个 PR"
- "检查这段代码的逻辑问题"
