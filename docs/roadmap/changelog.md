# 更新记录

## [2024-12-19] 🎉 统一数据库架构

### 重大更新
- **数据库统一**: 官网与简历匹配应用共享同一 PostgreSQL 数据库
- **用户表合并**: 登录凭证与计费数据统一到 `users` 表
- **架构升级**: 从 SQLite 迁移到 PostgreSQL，支持更高并发

### 安全增强
- JWT 跳转 Token 改为 5 分钟短期有效，减少泄露风险
- CORS 策略加固，限制允许的来源域名

### 技术改进
- Prisma 适配 PostgreSQL
- 用户 ID 统一为 Integer 格式
- 新增计费字段 `balance`、`free_quota`
